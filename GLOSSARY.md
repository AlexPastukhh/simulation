# GLOSSARY

| Термин | Значение |
|---|---|
| Actual Event | Фактическое событие подготовленного случая. |
| CURRENT | Фактическая архитектура выбранного момента. |
| State | Данные модели; параметры выбора явно отделены от фактов. |
| Plan / PlanRevision | Один план и его сохранённая версия. |
| BASE | Неизменяемый исходный фактический срез PlanRevision. |
| Evolution Step | Плановое изменение функции или реализации. |
| Target ArchitectureSnapshot | Полная плановая архитектура после Step. |
| EvolutionImpact | Описание перехода для одного Step и маршрута. |
| Forecast / прогноз | Ожидаемый исход или дата с основанием; ещё не факт. |
| Deadline / обязательный срок | Отдельное обязательство; смена оценки не меняет его автоматически. |
| Planned Change Axis | Ожидаемое направление изменений. |
| Actual Hot Path | Зона повторявшихся фактических изменений. |
| Candidate | Предложенный состав, который ещё не принят целиком. |
| Committed | Принятое решение в явно названной границе. |
| Authored assumption | Авторское допущение вымышленного случая, не измерение. |
| Reading copy | Снимок для чтения; не каноническое рабочее состояние. |
| Workspace | Универсальная среда экранов, окон, вкладок и их геометрии; отдельно от предметных данных подключённых профилей. |
| Workspace Event / open-content | Запрос к Shell найти или открыть и показать адресованный экземпляр содержимого. Не является предметным Actual Event. |
| Shell | Предметно-независимая оболочка, управляющая Workspace, навигацией и служебными настройками. |
| Content Profile / профиль | Подключаемая реализация конкретного применения Workspace: регистрирует содержимое, отрисовку и предметные данные/операции; например, Architecture Evolution Simulator. |
| Content identity / адрес содержимого | Идентификатор целевого экземпляра с учётом профиля; различает, например, два Markdown-файла одного типа. |
| Режим просмотра | Скрытие служебных элементов окон при сохранении работы содержимого и событий перехода. |
