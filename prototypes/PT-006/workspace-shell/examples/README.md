# Учебная эволюция архитектуры

`architecture-evolution.json` — вымышленный пример для исследования и будущей симуляции. Это данные для текущей оболочки, не принятый Scenario реального проекта и не автоматический engine.

## Маршрут

8 исторических событий: запрос → MVP → исправление validation → временный прототип комментариев → entity Comment вместо временного сервиса → статусы → запрос уведомлений → CURRENT и будущий Plan.

6 будущих Steps: email → очередь и повтор доставки → команды и доступ → вложения → поиск → webhook. Targets содержат соответственно 6/8/11/14/17/20 элементов. CURRENT содержит 4. Порядок авторский; каждый Step хранит независимый полный target, не исполняется от выбора.

Каждый historical checkpoint содержит архитектуру, известные тогда требования, файлы, работу, оценки, детали и Steps своего момента. Есть примеры ADD, MODIFY и REMOVE; файлы факта отделены от плановых эффектов. Unknown-время не равно 0. Все даты и evidence вымышлены.

## Просмотр

Из workspace-shell: `npm run build`, затем `npm run example`. Адрес по умолчанию: http://127.0.0.1:4212/ . Сервер слушает только loopback, обслуживает dist и не имеет API изменения данных.

Пример записывается только в совершенно пустой browser origin. Существующие или частичные записи не заменяются. Для другой независимой копии выберите свободный порт через PT006_EXAMPLE_PORT; например в PowerShell: `$env:PT006_EXAMPLE_PORT='4213'; npm run example`. Перезапуск сервера сам по себе не сбрасывает localStorage.

1. В Actual Events выберите факт; Current State покажет соответствующий срез.
2. Откройте Architecture Planning через Current State либо переключите экран. Архив read-only.
3. Вернитесь к рабочей архитектуре. В Plan выберите Step и нажмите «Открыть выбранную архитектуру»: повторное окно не создаётся.
4. В Impact History сравните факты; в Files и Evolution Impact отделите actual-файлы от будущих effects.

Браузерная проверка: PT006_SMOKE_MODE=full-content и PT006_SMOKE_URL с адресом примера, затем `node tests/single-architecture-ui-smoke.cjs`.

В репозитории хранится исходный пример. Редактирование в браузере меняет только эту браузерную копию. Автоматический replay, применение Steps, причинность и branching ещё не реализованы.
