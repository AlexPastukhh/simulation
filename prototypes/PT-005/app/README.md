# PT-005 · Single Plan / Conditional Evolution Steps

Disposable interactive semantic experiment, not a production architecture planning tool.

## Host commands

```powershell
npm ci
npm run check:model
npm run build
npm run lint
npm run dev -- --host 127.0.0.1
```

## Lenses and stage gates

- **A — Minimal Plan spine:** common source event/date, two architectures, ordinary conditional Evolution Steps, planned Architecture Snapshot after every Step, separate implementation outcome (including a code-only Step), predicted requirement never factual before its actual discovery.
- **B — Revisions and time:** independent actual branch cursors, unchanged shared external anchors, forecast vs fixed deadline, separate negotiated deadline, immutable R1, revisable qualitative expectations and Change Axes, branch-local requirements.
- **C — Contextual Fitness:** route-specific migration burden, plan alignment, work evidence, and counterfactual tradeoffs without scalar, probability or automatic winner.

Use the left date picker, architecture selector, PlanRevision switch, and Stage A/B/C navigation. The UI displays all three stages, but human UX interpretation remains pending until reviewed; automated checks are not VE promotion.

Plan/event fixture is script-author-provided: it does not claim empirical work-duration calibration or causal validation. All named dates and durations are synthetic examples.
